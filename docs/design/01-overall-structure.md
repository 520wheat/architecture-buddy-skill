# Design §1：整体结构与职责边界

## Status

Approved（2026-08-04）

## 名称与形态

- **名称**：Architecture Buddy
- **形态**：Agent Skills 协议下的 skill 包（可装 Cursor / Claude Code 等）
- **存放**：`Architecture Buddy/`（本工作区内）
- **与业务仓库**：解耦，独立维护

## 运行时两层（ADR-0003）

```text
┌─────────────────────────────────────────┐
│  Architecture Buddy（主持 Skill）         │
│  · 伙伴身份与共思节奏                       │
│  · 入口分流 A/B/C                          │
│  · 内化的第一性原理（抽核心问题）             │
│  · 问询是否做 Top N                        │
│  · 架构笔记 / 类问题模板产出                 │
│  · 圆桌编排（请谁入座、如何对照、不替你拍板）   │
└──────────────────┬──────────────────────┘
                   │ 按需调用
       ┌───────────┼───────────┐
       ▼           ▼           ▼
  架构师视角Skill  架构师视角Skill  …（构建期女娲蒸馏，运行时独立）
```
## 职责

| 谁 | 做什么 | 不做什么 |
|----|--------|----------|
| Architecture Buddy | 一起想、分流、抽核心问题、问 Top N、记笔记/沉淀模板、主持圆桌 | 不替用户做最终决策；不内嵌女娲；不假装是某位名人 |
| 架构师视角 Skill | 提供该人的心智模型/启发式/表达，用于对照 | 不主持流程；不接管对话主权 |
| 女娲（nuwa-skill） | 构建期蒸馏 FP → 写入主持 Skill；蒸馏架构师 → 独立包 | 不出现在运行时依赖里 |

## 构建期 vs 运行期

- **构建期**：女娲蒸馏第一性原理能力并合入主持 Skill；再蒸馏 2–3 位架构师为独立 skill
- **运行期**：默认只加载 Architecture Buddy；圆桌需要时再加载已安装的视角 Skill
