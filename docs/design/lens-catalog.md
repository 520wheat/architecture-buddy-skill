# Lens Catalog（架构立场透镜库）

依据 ADR-0016 / ADR-0017。  
**库内条目 >3**；圆桌当场从**已安装**子集中动态挑选 ≤3。  
每条须满足：有代表性架构设计 + 市场广泛验证 + 享誉世界的采用落点。蒸馏目标是**思想与做法**，不是口吻。

## 选席（主持用）

1. 钉对照点  
2. 排除 `not-for`  
3. 按 `best-for` 匹配，优先选**互有张力**的席  
4. 取 Top ≤3，向用户说明理由；允许用户换席  

运行时压缩索引：`architecture-buddy/references/lens-catalog.md`。
