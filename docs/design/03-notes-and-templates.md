# Design §3：架构笔记与类问题模板

## Status

**Approved（2026-08-05）** — 由深调研活表 v1.0 驱动（ADR-0012）  
用户确认批准；后续调研增量更新活表，不轻易改 M 编号。
## 原则

- 主产物：共写架构笔记；加分：够稳时沉淀类问题模板  
- 结构来自公开 canon + 多域样本 + 模式文献，不是自创  
- 模块/构建块视图仅附录  
- 模式按 **M9 层级**使用；GoF 默认不占主结构  
- 做架构即学习（ADR-0008）：按对话推进，关键分叉点明锚点即可  

## 架构笔记（主产物）

```markdown
# 架构笔记：<问题类一句话>

## 1. 问题类与边界（M1）
- 一类问题定义
- 包含 / 不包含（非目标）

## 2. 干系人与关注点（M2）
| 干系人 | 关注点 | 是否架构级 |

## 3. 约束与假设（M3）
- 硬约束（技术 / 组织 / 法规 / 运维边界）
- **一致性模型假设**（如 CP/AP、线性化等，若适用）
- **信任与威胁假设**（若适用；可对 ZTA/ASVS）

## 4. 架构显著需求 / 质量目标（M4）
| 质量目标 | 场景（刺激→响应→度量） | 优先级 | 明确不优化 |
| 可选：相关可验证要求（如 ASVS 条目）作检查提示 |

## 5. 机制与策略（M5）
### 5.1 机制（共性）
- …
- 常见结构提示：控制面/数据面？元数据/数据？一等中间表示？日志？…
- 对应公共模式名（POSA / EIP / Raft 族 / Agent 模式…）

### 5.2 策略选项（差异）
| 策略或模式 | 层级* | 适用条件 | 代价/后果 | 状态 |
|------------|-------|----------|-----------|------|

\*层级：架构 · 企业 · 集成 · 并发分布式 · Agent · 细粒度

## 6. 关键决策（M6）
### ADR-标题
- Context（价值中立的力）
- Options（含未选）
- Decision（We will…）
- Consequences（正/负/中性）

## 7. 权衡、风险与未决（M7）
- 质量目标冲突 / 敏感点 / 风险
- 推迟项与验证计划

## 8. 证据与学习痕迹（M8）
- Top N / 圆桌摘要（若有）
- 参考 canon 与样本
- When not / 本次学到的一句话

## 9. 模式索引（M9，可选短表）
| 模式名 | 层级 | 用在何处 |

## 附录（按需）
- 构建块 / 上下文图
- 细粒度 GoF 清单
```

## 类问题模板（加分产物）

```markdown
# 模板：<问题类名>

## 何时使用 / 何时不用
## 核心问题清单（M1–M4）
## 默认机制（及常见模式名）
## 策略目录（按 M9 层级；含条件与代价）
## 常见反模式（可引用 living/anti-patterns）
## 决策检查清单（何时写 ADR）
## 安全/一致性检查提示（若该类相关）
## 落地提示（指向系统设计，不替代本模板）
## 修订记录
```

## 共写用法

- 不必按 1→9 填空；对话自然覆盖锚点  
- 分叉处可说：「我们在澄清信任假设（M3）」「这两个是 M5 策略」  
- 出现可复用结构 → 优先问公共模式名（M9）  
- 提出 Agent / 总线 / 共识组件前：先问更简单方案是否足够
