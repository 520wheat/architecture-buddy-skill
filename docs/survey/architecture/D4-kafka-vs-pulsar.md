# 对照短记：Kafka vs Pulsar
- 域: D4 · Phase 2 · 2026-08-05

## 机制共性
- 持久日志、分区/分片并行、多消费者、容错副本
- 批处理与顺序写优化

## 策略分叉（写进 M5）
| 问题 | 偏 Kafka | 偏 Pulsar |
|------|----------|-----------|
| 运维简单、日志心智统一 | ✓ | 组件更多 |
| 存储与服务独立扩缩 | 经典共置（有分层存储演进） | BookKeeper 分离 ✓ |
| 统一实时数据平台叙事 | Design 文开篇即此 | 消息平台+地理复制叙事 |
| 云上统一入口 | 需自建发现/LB | Proxy 一等可选 |

二者都不是「队列 ack 状态机」传统模型；选前对齐问题类。
