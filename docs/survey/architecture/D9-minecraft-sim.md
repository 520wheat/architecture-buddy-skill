# Minecraft — 多人共享体素/实体模拟（问题类短摘）

- 域: D9 共享模拟世界 / 游戏状态同步
- 来源: https://minecraft.wiki/ · https://wiki.vg/Protocol · PaperMC / 代理与模组生态公开文档
- 阶段: Phase 3 · 2026-08-05
- 诚实边界: **无官方完整架构白皮书**；下文为公开 wiki/协议/社区资料的合理重构

## 问题类

多人共享**体素世界 + 实体模拟**：谁拥有权威状态、如何按 tick 推进、如何按兴趣/区块把状态同步给客户端、客户端如何预测与和解、内容如何在数据/模组边界扩展——**不是**「怎么写 Bukkit/Paper 插件」教程。

## 硬约束

- 作弊与不一致：客户端不可信 → 服务端权威
- 带宽与 CPU：全图广播不可行 → 兴趣区域 / 区块级同步
- 手感：纯等服务端确认会「黏」→ 客户端预测 + 和解
- 模组生态：扩展点必须与权威模拟边界共存，否则协议与存档撕裂

## 机制（共性）

1. **服务端权威世界状态**（方块、实体、库存等）
2. **固定节奏 tick 模拟**（经典心智约 20 TPS）
3. **区块加载 + 视距/兴趣管理**决定谁收到哪些更新
4. **协议包同步**（社区文档化的状态机与包方向）
5. **客户端预测 / 和解**（移动等本地先行，冲突时以服务端为准）
6. **存档与区块持久化**边界（在线模拟 vs 磁盘区域）
7. **数据驱动 / 模组加载器**扩展内容与行为，但权威仍在服务端模拟侧

## 策略（差异/选项）

| 维 | 选项 | 备注 |
|----|------|------|
| tick 调度 | 单线程世界 tick | 经典；易推理，易成热点 |
| | 区域/线程并行（如 Folia 心智） | 吞吐；跨区交互变难 |
| 拓扑 | 单逻辑世界权威服 | 简单一致性 |
| | 代理 + 多逻辑服 | 扩容与玩法隔离；跨服状态另议 |
| 预测强度 | 弱预测 / 强预测 | 手感 vs 和解复杂度、作弊面 |
| 扩展 | datapack/数据驱动 vs 深度模组/改协议 | 兼容面与分叉成本 |
