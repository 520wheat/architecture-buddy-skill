## 学到的决策写法（机制）
每条决策尽量具备：
- **目标**（为何要决）
- **决策标准**（力）
- **备选方案**（策略并列）
- **选择与隐含代价**（如推迟外链检查 = 范围策略）

## 样本决策摘要
| 决策 | 选择 | 排除 | 标准 |
|------|------|------|------|
| 外链检查 | 推迟 | 当前版本做 | 范围/风险控制 |
| HTML 解析 | jsoup | HTTPUnit | 少依赖、DOM API |
| 字符串相似度 | Jaro-Winkler 源码嵌入 | 等二进制依赖 | 可得性 |
