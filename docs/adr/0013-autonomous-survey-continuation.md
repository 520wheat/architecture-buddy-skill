# ADR-0013: 调研自主推进；非重大分歧不打断

## Status

Accepted

## Context

§3 已批准。用户指示：后续调研自动进行；不影响 skill 效果的重大分歧不必停下询问。

## Decision

1. Agent 在书单与退出标准框架内自主加深调研、更新 `docs/survey/` 与活表。
2. 仅当出现会改变 Architecture Buddy **核心身份、运行时结构（主持+视角）、产物定义（M1–M9）、或构建期/运行期边界** 的分歧时，才暂停征求确认。
3. 例行加深（更多样本、模式表补全、对照短记）直接落盘并在阶段性摘要中汇报。

## Consequences

- 调研吞吐提高；聊天中减少确认回合。
- 重大架构分叉仍保留人审闸门。
