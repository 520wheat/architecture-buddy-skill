# ADR-0004: 入口模式、产物与 Top N 调研策略

## Status

Accepted

## Context

用户可能带着不同起点进入：模糊问题、已有方案、或明确要做竞品/类问题抽象。  
Top N 成功产品对抽象机制/策略帮助大，但调研成本高，不能擅自开跑。

## Decision

### 入口（均需支持，由主持 Skill 识别并切换）

| 模式 | 用户带来什么 |
|------|----------------|
| A | 模糊的真实问题 |
| B | 已有方案，需一起审视 |
| C | 一类问题的调研/抽象意图 |

### 产物

- **主产物**：共同写就的架构笔记（问题类、机制、策略选项、取舍、未决点）
- **加分产物**：抽象够稳时，沉淀为可复用的「类问题模板」

### Top N

- Skill **主动询问**用户是否开展 Top N / 对照调研
- 用户同意后再执行；不同意则用已知模式做轻量对照或跳过

### 领域范围

- 第一版深耕**软件/互联网产品系统**
- 接口与叙事不写死，预留扩展到更广技术系统

## Consequences

- 主持流程必须包含模式识别与 Top N 问询节点。
- 笔记格式需同时服务「当场决策」与「日后沉淀模板」。
- 领域扩展通过后续 ADR/视角包完成，不阻塞 v1。
