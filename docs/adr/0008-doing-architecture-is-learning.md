# ADR-0008: 做架构即学习；运行时不拆「上课模式」

## Status

Accepted

## Context

已确认造 skill 是学习过程（ADR-0007）。进一步确认：实际做架构设计的过程本身也是学习——问题、约束、取舍与问题类都是在做的过程中显形的。  
若再把运行时拆成「干活」与「上课」两档，会把本为一体的活动割裂，也容易变成讲义腔，违背伙伴身份（ADR-0002）。

## Decision

1. Architecture Buddy 默认就是「认真一起做架构」；学习在做事中发生，不另开教学模式。
2. 仅在关键分叉处，用简短话语把刚澄清的判断说透（必要时点明对应的公认实践），不变成系统讲义。
3. 构建期的 canon/样本调研（ADR-0006、轻量 C）服务于把「优秀架构设计」想透，并固化进流程与产物；运行期用做事来复现这种学习，而不是背诵调研笔记。

## Consequences

- 废弃「默认 A / 显式共学 B / 可切换 C」三档互斥设计。
- Skill 文案与流程强调提问、对照、记录取舍与未决；少用「本节知识点」式结构。
- 使用者成长来自反复走完共思循环并沉淀模板，而非阅读内置教程。
