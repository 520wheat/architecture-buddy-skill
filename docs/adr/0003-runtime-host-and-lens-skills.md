# ADR-0003: 运行时 = 主持 Skill + 独立架构师视角；女娲仅构建期

## Status

Accepted

## Context

需要两类能力：

1. **第一性原理**：帮助与用户一起抽出核心问题（几乎每次都用）
2. **顶级架构师视角**：圆桌对照时按需使用（2–3 席）

曾考虑运行时内嵌 nuwa-skill，但会臃肿，并把「造人工厂」与「架构伙伴」耦死。  
女娲应用于**蒸馏出所需能力**，而不是作为运行时依赖。

备选结构：

- A：第一性原理与架构师全部为独立可调用 Skill
- B：第一性原理合入主持 Skill；架构师保持独立 Skill
- C：第一版全部塞进主持 Skill，以后再拆

## Decision

采用 **B**：

| 构件 | 形态 | 来源 |
|------|------|------|
| Architecture Buddy（主持） | 单一主持 Skill | 含共思流程；第一性原理经女娲蒸馏后**写入**主持 Skill |
| 架构师视角 | 独立可调用 Skill | 构建期用女娲蒸馏，运行时按需加载 |
| 女娲（nuwa-skill） | 构建期工具 | **不**内嵌、**不**作为运行时依赖 |

若未来需要多派第一性原理切换，再将 FP 拆成独立席（B → A），成本可控。

## Consequences

- 只安装主持 Skill 即可进行有效共思。
- 架构师视角可增、可换、可独立升级，而不膨胀主持 Skill。
- 构建流水线与运行体验分离，避免臃肿。
